# Far Sightedness Testing App

Tumbling E vision chart for quick at-home far-sightedness screening. Not a medical diagnosis.

**Live app:** https://ubaid792792.github.io/far-sightedness-test/

## How to use

Open `index.html` on a screen at the stated distance and follow the prompts. `tumbling-e-chart.html` is the plain chart; `archive/` holds earlier versions.

## Privacy

No API keys or personal data are stored in this repository.
